# 第二个独立样本：沪深 300 蓝筹 / 白马 20 只，回放验证

日期：2026-11-27　规则指纹：`cv1-6d186740a3`（`rules-2.6.3` + 当前参数默认值）

这份报告回答一个问题：**同一套战法与守卫链，换到「非红利」的蓝筹/白马股上还成立吗？**

- 样本 A（对照）：红利类 ETF 成分 20 只（D-30，`data/cache/dividend_pool.json`）
- 样本 B（本次）：沪深 300 里按蓝筹/白马口径筛出的 20 只（`data/cache/blue_pool.json`）

两个样本用**完全相同**的回放口径：460 个交易日（2025-01-02 ~ 2026-11-26）、含分红再投
（前复权，红利税 10%）、注入大盘 `sh000001`、注入板块三档、注入估值分位与分红事实、
参数标准档。

---

## 1. 样本 B 怎么来的（可复现，不含主观挑选）

`scripts/assistant_pick_blue_pool.py`，与红利池脚本 `assistant_pick_dividend_pool.py`
**同一套筛法骨架**（`passes()`、`fetch_valuation`、`fetch_financials` 都是复用的），
只改两处：来源与门槛。

| 项 | 样本 A（红利） | 样本 B（蓝筹/白马） |
| --- | --- | --- |
| 来源 | 10 只红利主题 ETF 最新季报持仓并集（139 只） | 沪深 300 现成分（接口 300 行 / 去重 289 只） |
| 排除 | — | **排除样本 A 已用的 20 只**（其中 7 只在沪深 300 内） |
| 市值下限 | 100 亿 | **500 亿** |
| 年化加权 ROE | ≥ 10% | **≥ 12%** |
| PE_TTM | (0, 40] | **(0, 60]** |
| 净利同比 | > 0 | > 0 |
| 非金融资产负债率 | ≤ 70% | ≤ 70% |
| 行业上限 | 2 只/东财一级行业 | 2 只/东财一级行业 |
| 抽样 | 分层随机，seed=20261126 | 分层随机，seed=20261126 |

- 过筛 84 只 → 行业上限 + 分层随机取 20 只，落在 **13 个行业**：
  贵金属×2、化学制品×2、软件开发×2、消费电子×2、通信设备×2、航运港口×2、电力×2、
  白色家电、光伏设备、游戏、调味发酵品、玻璃玻纤各 1。
- PE 上限从 40 放宽到 60 是刻意的：成长型白马（新能源、医药、科技）估值本来高于红利股，
  用 40 筛会系统性剔掉「白马」这一半。**其余门槛对 300 只一视同仁**，剔除理由逐条落
  `data/cache/blue_pool_rejected.json`（198 条）。
- 板块映射 **20/20**。其中海天味业（603288）的东财二级「调味发酵品Ⅱ」在同花顺没有同名板块，
  新增别名指向「食品加工制造」——这是**上位行业**匹配（调味品是食品加工的子集），
  与其他三条「同词异序」的别名性质不同，已在 `sector_map.py` 注明。

## 3. 三个结论

**① 胜率与赔率此消彼长，期望几乎没变。** 红利 64.2% × 1.36，蓝筹 54.6% × 1.82——
两条路走到同一个期望。差别在形态：高波动白马**止损被打掉的次数从 31 增到 49**（占闭合
38% vs 25%），但赢的时候幅度大得多（均盈 +11,693 vs +7,521）。这是同一套「突破/回踩 +
止损止盈」逻辑作用在不同波动率标的上的必然结果，**不是策略对哪类股票更适应**。

**② 相对「同期拿着这只股票」没有择时增益。** 对每笔闭合回合做配对：
用同一只标的、同一条含分红序列，算买入持有到同一出场日的收益，再看策略这笔的毛收益差：

| 样本 | 配对笔数 | 均差 | 标准差 | t | 跑赢比例 |
| --- | --- | --- | --- | --- | --- |
| A 红利 | 123 | **+0.22pp** | 3.5pp | 0.72 | 51.2% |
| B 蓝筹 | 130 | **+0.04pp** | 2.9pp | 0.15 | 50.0% |
| 两样本之差 | — | −0.19pp | — | −0.47 | — |

也就是：止损/止盈这套出场规则，相对「同一段一直拿着」**既没有显著赚到，也没有显著亏掉**
（t < 1，胜率 50%）。两个样本都如此，两样本之间也没有差别。

## 4. 共同的问题（两个样本都出现，与股票池无关）

1. **2026 段普遍退化**：A 61.8%、B 49.1%，盈亏比 1.01 / 1.25。两个池子在 2026 都接近抛硬币，
   而 2026 的买入持有收益只有 +4.7% / +1.7% —— 没有趋势可跟。
2. **闭合样本量偏小**：460 个交易日只闭合 123–130 笔（每只 6–7 笔）。S1 之外（S2/S4）
   样本 16 笔，统计上不够用。
3. **出场规则不产生 alpha**：见结论 ②，两个样本的配对差都是 0（t<1）。
4. **策略本质是趋势跟随**：所有收益来自「少数几笔大幅盈利 + 高胜率小亏」，一旦池子里
   没有走出趋势的票，期望就归零。

## 5. 局限（不能从这份报告读出来的东西）

- **成分股是今天的名单**：沪深 300 现成分 + 红利 ETF 现持仓，回放窗口在 2025–2026。
  被调进指数/ETF 的往往是前一段涨得好的，两个样本同样受影响——所以「两个样本谁更好」
  可比，「这套策略的绝对收益」不可外推。
- **没有资金曲线**：回放按每笔固定名义本金（平均 ~6 万）模拟，不加权、不限制同时持仓数、
  不模拟资金耗尽。总净盈亏不能当组合收益率看（`not_modelled` 里明写）。
- **部分成交 / 停牌 / 涨跌停不成交**未建模；分红按固定 10% 税率、除权日不单独再投。
- **做 T 分支与分级止损多档减仓**未建模。

## 6. 复现

```bash
# 1. 选样（会缓存沪深 300 成分到 data/cache/hs300_cons.json）
python scripts/assistant_pick_blue_pool.py --limit 20 --per-industry 2 \
    --out data/cache/blue_pool.json --rejected data/cache/blue_pool_rejected.json

# 2. 补数（日线 / 分红 / 估值 / 板块 / 大盘；板块映射单独一份，别覆盖红利样本的）
python scripts/assistant_ingest_history.py --db data/cache/blue20.db \
    --codes 000333 605117 002602 000975 600489 600309 600160 300033 688111 603288 \
            600176 601138 300866 000338 300394 600522 601919 600026 600674 600025 \
    --start 2023-11-17 --end 2026-11-26 --dividends --valuations --sectors --index sh000001 \
    --sector-map data/cache/assistant_sector_map_blue.json

# 3. 回放
python scripts/assistant_backtest_replay.py --db data/cache/blue20.db \
    --codes 000333 605117 002602 000975 600489 600309 600160 300033 688111 603288 \
            600176 601138 300866 000338 300394 600522 601919 600026 600674 600025 \
    --start 2025-01-02 --end 2026-11-26 --index sh000001 \
    --adjust total_return --dividend-tax 0.10 --sectors --valuations \
    --sector-map data/cache/assistant_sector_map_blue.json \
    --out data/cache/blue20_full.json
```

产物：`data/cache/blue20.db`（L1 数据）、`blue_pool.json` / `blue_pool_rejected.json`
（选样与剔除理由）、`blue20_full.json`（逐笔回合与统计）。按现有约定，这些都在 `data/`
下、不入版本控制。
