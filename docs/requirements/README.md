本目录集中存放本仓库各项目的**需求规格**。方案 / 设计文档按仓库约定放在 `docs/solution/`，不在本目录。

## 约定

- **通用目录 + 项目前缀命名**：`<项目名>-requirements-vX.Y.md`，便于同一目录容纳多个需求；方案文档对应 `<项目名>-solution-vX.Y.md`，放 `docs/solution/`。
- **只留最新版**：同类文档同目录只保留最新版本，升版时移除旧版；历史变更看 `docs/CHANGELOG.md` 与 git 记录。
- **状态标注**：文档头部标明「草案 / 待决定 / 已批准 / 已替代」。未标注「已批准」的内容都不是实施授权。
- **原话与解释分离**：需求文档附录保留原始需求原话；正文为结构化改写，新增的产品解释、假设与待确认项单独标注。
- **范围边界**：本目录只做需求澄清；代码实现位于 `src/`、`api/`、`apps/dsa-web/`，验证记录与变更同步 `docs/CHANGELOG.md`。
