## 4. FR-4 关键价位

按「必须有 / 建议有 / 可选」三级管理，避免字段虚报。

| 级别 | 字段 | 要求 |
| --- | --- | --- |
| **必须有** | 支撑位 | 1–2 个 |
| **必须有** | 压力位 | 1–2 个 |
| **必须有** | 趋势失效位 / 止损参考位 | 1 个 |
| **必须有** | 每个价位的**来源说明** | 前高前低 / 箱体边界 / 重要均线 / 缺口等 |
| 建议有 | 关注买点区 | 未持仓时 |
| 建议有 | 减仓 / 止盈区 | 已持仓时 |
| 建议有 | 仓位建议 | 服从不超仓规则（见 FR-5） |
| 可选 | 突破确认位、回踩确认位 | — |

**验收要点**：任一价位缺来源说明即判卡片不完整；「必须有」字段不得为空，无值时应显式标注「数据不足」而非填空或编造。

## 5. FR-5 仓位管理

### 5.1 硬上限（统一口径，不可突破）

| 约束 | 公式 |
| --- | --- |
| 单只上限 | `单只市值 / 总资金 ≤ 20%` |
| 总仓位上限 | `总持仓市值 / 总资金 ≤ 80%` |
| 现金下限 | `现金 ≥ 总资金 × 20%` |
| T 仓计入 | T 仓**同时**计入单只 20% 与总仓位 80% 限制 |

### 5.2 建议层

- 采用「**统一硬上限 + 动态基础建议 + 行业集中度提示**」三层结构。
- **不按股票/ETF 种类设行业硬上限**；行业集中度**只提示、不硬限**。
- 卡片显示：**百分比区间 + `轻` / `中` / `重` 档位**。
- 优先级：硬上限 > 动态基础建议；位置标签、趋势评分只影响建议层，不得突破硬上限。

**〔已决定〕** 总资金＝用户填写的固定金额，一般不变、可调整（Q1，2026-11-10，见 §14.3）：所有硬上限以该数值为分母，**不随市值每日重算**；金额变更须留痕并在卡片标注所采用口径。

**〔已决定〕** 动态基础建议的评分口径与档位映射（Q4/Q5，2026-11-10，见 §14.3）：
- 评分输入＝**趋势档 + 位置标签 + 评分/置信度 + 大盘强弱 + 所属板块强弱**。大盘与板块均取自行情结构数据（指数涨跌、板块涨跌/排名），**不属于 NG-4 的「消息面情绪判断」**，不得引入新闻、舆情或情绪打分。
- 行业集中度：**单一行业持仓占比 ≥ 25% 时提示**，只提示不硬限，阈值写成配置项。
- `轻` < 10%、`中` 10~15%、`重` 15~20%（分母为固定总资金，与单只 20% 硬上限对齐）；三个端点均为配置项，纸面回看后可微调。
- 上述新增输入需补充「指数 / 板块行情」的数据源准入与降级口径，见 §7。

**验收要点**：对每张卡片反算仓位，单只与总仓位均不得越界；建议区间上限不得超过该标的剩余可用额度。

## 6. FR-6 做 T 规则

| 编号 | 需求 | 状态 |
| --- | --- | --- |
| FR-6.1 | 短波 T：几天到两周不限；允许单 T | 已明确；「单 T」**已决（Q6）**＝单边不闭合、不强制买回配对，T 仓可跨日持有，见 §14.3 |
| FR-6.2 | **底仓不动**，只用 T 仓做 T | 已明确 |
| FR-6.3 | T 仓 ≤ 当前该股最高可用资金的 **10%** | 已明确 |
| FR-6.4 | `当前股最高可用资金 = min(20% × 总资金 − 该股现有底仓市值, 现金可用部分)` | 已明确 |
| FR-6.5 | T 仓计入单只 20% 与总仓位 80% 限制，**不得超仓** | 已明确 |
| FR-6.6 | 允许反 T，但**必须有底仓**；反 T 只允许卖出 T 仓，底仓不动 | 已明确；时序 **已决（Q7）**：卖出已持有 T 仓、买回可跨日、底仓始终不动、无 T 仓则不生成反 T 计划，见 §14.3 |
| FR-6.7 | **禁止杠杆/融资** | 已明确 |
| FR-6.8 | 单次 T 亏损上限：`总资金 × 0.75%` | 已明确 |
| FR-6.9 | 工具**只给盘前 T 计划**：参考区间、失效位、T 仓上限、止损参考；**不给盘中实时信号** | 已明确 |

**〔解释〕** 当 `20% × 总资金 − 底仓市值 ≤ 0` 或现金不足时，T 仓上限为 0，卡片不出 T 计划并标注原因。此为满足 FR-6.5 的必然推论；Q1 已确认总资金为固定金额，该推论一并生效，但 `现金可用部分` 仍需单独录入或由持仓推算，不得静默用总资金倒推（§14.3-Q1）。

**验收要点**：T 仓金额、单次 T 最大亏损须同时满足 FR-6.3/FR-6.8 与 FR-5 硬上限；任一越界即判失败。

## 7. FR-7 数据源与质量

### 7.1 准入与取数策略

- 准入：**免费、无需 token、无积分、稳定优先；不稳定接口排除**。
- 主源 **akshare** → 公开接口备用 → 本地缓存兜底；**质量校验后降级**。

### 7.2 降级 / 排除触发

| 触发条件 | 动作 |
| --- | --- |
| 该源**连续 3 个交易日**取数失败 | 降级或排除 |
| **关键字段缺失率 > 5%** | 降级或排除 |

### 7.3 其余口径

- 基本面数据**按季度更新并缓存**，取数失败**不阻塞报告**。
- 报告注明**数据日期**与**数据源**；使用缓存数据时**明确标注**。
- 自选股与持仓**手动配置**。

**〔待补充，源于 Q4 已决口径〕** 建议层评分纳入大盘强弱与所属板块强弱，因此数据源准入需**额外覆盖指数行情与板块涨跌/排名**，并沿用 §7.2 同一套降级与排除触发；个股与所属行业/指数的映射口径在方案阶段确定。这两类数据同样免费无 token，取数失败时**只影响建议层评分，不得阻塞卡片输出**（与基本面失败不阻塞同口径）。

**〔已决定〕** 数据质量默认口径（Q8，2026-11-10，见 §14.3）：关键字段＝日期/开/高/低/收/成交量（另加指数与板块字段）；缺失率窗口＝近 20 个交易日；白名单＝akshare 公开接口为主、腾讯/新浪备用；缓存＝当日收盘后至次日盘前、跨交易日失效；交易日历＝数据源交易日历。**五项均为默认值且全部可配置**，§7.2 的缺失率判定按此窗口计算。

**验收要点**：报告可追溯到每个字段的日期与来源；缓存数据有可见标识；基本面失败时仍能出报告。

## 10. FR-10 卡片结构

顺序固定，不得调换：

```
操作意见 → 趋势结论 → 当前位置 → 关键价位 → 理由 → 风险提示
        → 仓位建议（百分比区间 + 轻/中/重）→ 做 T 计划
```

### 10.1 字段契约〔解释性补全，供方案阶段细化〕

| 区块 | 关键字段 | 必填 | 空值处理 |
| --- | --- | --- | --- |
| 操作意见 | 意见枚举、持仓状态、数据截止日 | 是 | 异常态按 FR-3.5 / FR-8.7 标注 |
| 趋势结论 | `偏强`/`中性`/`偏弱`、B 方案说明 | 是 | 数据不足则标注，不猜档 |
| 当前位置 | 高位/低位/中性/不明、同向指标数 | 是 | 冲突时降级为中性/不明 |
| 关键价位 | 支撑 1–2、压力 1–2、失效位/止损位、各价位来源 | 是 | 显式「数据不足」 |
| 理由 | 技术面主因、基本面/估值辅助 | 是 | 辅助缺失需标注 |
| 风险提示 | ST、停牌、行业集中度、位置风险、缓存数据 | 是 | 无风险也需明示「无特别提示」 |

## 19. 共享数据底座与命名裁定（三页一致性的根基）

### 19.1 一次决策、四处只读

盘前（**非交易日全局不触发**，§14.4）决策引擎**只跑一次**，产出 4 个共享对象，均携带一致性三元组 `[data_date, snapshot_id, calc_version]`：

| 对象 | 内容 | 主要消费方 |
| --- | --- | --- |
| `market_snapshot` | `market_regime` 三档 + `regime_degraded` + 指标网格 | Tab A 上半、建议层、详情 5c |
| `sector_snapshot[s][t]` | `sector_strength`（多日同构三档）、全市场分位、相对大盘强弱、涨跌家数、领涨股、degraded | Tab A 下半、建议层、详情 5b |
| `holding_conclusion[code][t]` | **单只标的决策主对象**；`advice` 唯一真值载体 | 列表建议列、详情操作意见、板块提醒条（方案 A）、大盘 B6 计数 |
| `watchlist_conclusions` | `items[] + counts + 三元组` | 列表、大盘 B6 计数 |

建议层评分在引擎内对每只标的**算一次**写入 `advice`；列表行 / 详情操作意见 / 板块提醒条 / 大盘 B6 计数**一律只读、禁止 recompute / rewrite / 按板块或大盘推导改写**。详情页「分析过程」只展开中间量做解释，不重跑模型。

### 19.2 一致性三元组硬校验

- 任何位置渲染 `advice` / 涨跌幅 / 大盘 / 板块字段**前**硬校验 `[data_date, snapshot_id, calc_version]`；不一致 → 显示「待同步」且**不显旧值**。
- 大盘 B6 总结段额外硬校验 `sum(counts) == len(watchlist)`；不等则**不输出总结段**并报数据异常。
- 停牌、数据不足**单独计数，不并入观望**。
- URL 若带 `data_date` / `snapshot_id` **不用于渲染**，一律以当前全局快照为准（防旧书签看到过期结论）；`advice` 不放 URL。

### 19.3 命名裁定（主理人统一，三份成员产出按此收敛）

### 19.4 口径边界（防止三页分叉）

- `market_regime`（大盘环境档，2×2 多日）与 `trend`（个股序列趋势档）**枚举同构、语义独立、不可互相代入**。
- `rs_t`（单日算术差，仅展示分档）**不得进评分**；`sector_strength` 用**多日序列 + 同款决策框架**判档，单日值不得判档。
- `market_baseline.pct_change` **仅供板块相对强弱基准**，不改变建议层接口；单日涨跌幅标量、板块单日 rs **均不进建议层**。
- 建议层输入固定为 `trend + position_tag + score/confidence + market_regime 三档 + sector_strength 多日三档`。
- **P0-4 已拍板**：`market_baseline.baseline_index_code` = `primary_index_code` = **上证 `sh000001`**，同时决定 `market_regime` 计算主体与主要指数条「主」标，三处同源、不得分设。板块三档转建议层评分走**可配置分值映射表**（`sector_strength` / `market_regime` 各档 → 权重），**不直接用涨跌幅数值或单日 `rs_t`**；权重为可配置项、数值留 D2 纸面回看确定，变更记入 `calc_version`。
- `position_tag(series, config)` / `trend(series, config)` 为**纯序列函数**，无个股专属逻辑，指数序列可直接调用；板块层「≥2 类同向」为**板块独立规则**（多日窗口内主指标同向计数），不复用该函数。
- 涨跌家数 / 领涨股统一降为**参考展示层，不参与硬结论**（三页同层级同降级）。
- **同名不同实体，实现必须用完全限定名**：`market_baseline.pct_change`（大盘基准涨跌幅）与 `holding_conclusion[code].pct_change`（个股价涨跌幅）、`sector_snapshot[s][t].pct_change`（板块涨跌幅）字段名相同但实体不同。板块 R4 若误取个股价，`rs_t` 口径会整体错位；三者一律以完整前缀读写，不得用局部别名简化。
- **禁用词表范围收窄**：仅约束 Tab A 上半**自产**的节奏文案；枚举标签引用（如板块提醒条引用 advice）不受约束，见 §23 P0-1。
- 大盘/板块降级**只降置信度 + 注记，不改 advice 档位**；**不因大盘环境改变个股既定动作**。

## 20. Tab A 上半 · 大盘分析区

### 20.1 区块顺序（自上而下）

| 序 | 区块 | 作用 |
| --- | --- | --- |
| 1 | 交易日/缓存状态条（Tab A 上下半共用） | `data_date`、是否交易日、`source_tag`、降级状态；非交易日整区不触发 |
| 2 | 主要指数条 | **主指数固定上证 `sh000001`（P0-4 已拍板）** 点位与涨跌幅 + 深证/创业板等辅助指数小字；成长风格由风格对比补足，并标注「主指数为上证指数，成长风格请参考风格对比」 |
| 3 | 核心指标网格（约 6 格） | MA20 位置、均线排列、量能比、RSI、20 日位置、5 日涨幅 |
| 4 | 市场宽度（L2 可选） | 涨跌家数、风格；**不参与硬结论** |
| 5 | 环境评级 + 节奏建议 | `market_regime` 三档 + 一句节奏 + 恒定尾句 |
| 6 | 一段总结 | 描述指数与量能，末句联动自选股动作统计（B6） |

### 20.2 环境评级 M1：2×2 四格 → 三档（完整定义）

> 本定义由 `market-reader` 产出，为**大盘区硬判定主框架**。`sector_strength` 若选择「同构 M1」则复用此结构（见 §23 P0-5）。

**因子 A · 价格相对均线**：`C_t > MA_t×(1+ε)` → `above`；`C_t < MA_t×(1−ε)` → `below`；其余 → `near`（**缓冲带**）。
- `near` 时**沿用上一交易日有效档**（防临界抖动），无历史档 → `direction_undetermined` → 走降级链。
- 因子缺失（MA 不可算）→ `direction_undetermined`，**不猜测、不补值**。

**因子 B · 均线斜率**：`slope = MA_t / MA_{t−k} − 1`；`slope > θ` → `up`，否则 → `not_up`。
- **严格二分**：走平并入 `not_up`，保持四格闭合；不引入第三斜率档。

**四格映射表**：

| 象限 | 因子 A | 因子 B | `market_regime` | 节奏文案方向 |
| --- | --- | --- | --- | --- |
| Q1 | `above` | `up` | 偏强 | 顺趋势、不追高 |
| Q2 | `above` | `not_up` | 中性 | 动能减弱，等确认 |
| Q3 | `below` | `up` | 中性 | 趋势回调，等企稳 |
| Q4 | `below` | `not_up` | 偏弱 | 防守优先，不重仓 |

> Q2/Q3 即此前被误判为「震荡」的两个象限，已按 §2 评审结论单列文案。

**量能：第 3 因子仅作确认标注，不进硬判定**

| 量能比 | 确认标签 |
| --- | --- |
| ≥ 1.1 | 放量 |
| ≤ 0.9 | 缩量 |
| 其余 | 平量 |

- 量能字段缺失 → `regime_active_factors = 2`、`volume_confirm_available = false`、量能确认位**整块隐藏**（不留空字符串/0 值）、`degraded_flag` 记「量能确认不可用」；**`regime_degraded` 仍为 `false`**——确认层降级 ≠ 三档结论不可信，**三档档位不变**。
- `MA5 > MA10` 从硬门槛降为**修饰条件**，只影响节奏文案用词，不改档位。

**输出契约**：`market_regime ∈ {偏强, 中性, 偏弱}`、`regime_degraded: bool`、`regime_active_factors: int`、`volume_confirm_available: bool`、`regime_quadrant ∈ {Q1..Q4, direction_undetermined}`、`regime_degraded_reason: str`、`data_date` / `snapshot_id` / `calc_version`。

**`regime_degraded = true` 的穷举触发**（其他一律 false）：
1. 价格或 MA 序列不足 `min_valid_bars`
2. 关键字段缺失率 > `missing_rate_threshold`
3. `direction_undetermined` 且无历史有效档可沿用
4. 数据源标记 `date_mismatch`（跨交易日拼接）
→ 触发时输出 `中性 / 不明` + 明确原因文案，**不得输出偏强或偏弱**。

**可配置阈值清单**（数值留 D2 纸面回看确定，全部进 `calc_version`）：
`ma_window`、`slope_lookback_k`、`slope_theta`、`ma_buffer_eps`、`lookback_n`、`vol_ma_window`、`vol_deadzone_alpha`、`missing_rate_threshold`、`min_valid_bars`。

**降级总则**：宽度 / 风格 / 指数共振 / 量能确认缺失，**只减少展示项，不改已有硬结论档位**。`high20 == low20`（停牌/一字板）时 20 日位置分母为 0 → 返回 `null`，该项按降级处理，不「部分指标显示 -」。

**主指数专属、不可同构复用**：M4 指数共振、M5 市场宽度、M6 风格，以及 `p` / `K` / `δ` / `width_r_hi,r_lo` 等配置。

### 20.3 字段契约（摘要）

| 字段 | 来源 | 更新 | 缺失降级 | 必显 |
| --- | --- | --- | --- | --- |

| `source_tag` / `degraded_flag` | P | 同上 | 恒可得 | 是 |

### 20.4 结论与禁用词

- 只输出「**环境 + 节奏 + 恒定尾句**」；恒定尾句为「**个股仍按各自纪律执行**」，用于防大盘与个股「清仓」建议打架。
- **禁用词表**（仅限本区自产节奏文案）：加仓、减仓、清仓、建仓、买入、卖出、几成仓、建议总仓位；以及「必涨/必跌/稳赚」等收益承诺。
- **不给建议总仓位百分比**；总资金/总仓位校验只在 Tab B 组合层出现。
- 总结段第三句统计自选股动作分布（减/清、加/建、持有、观望、无信号），**计数与 Tab B 列表同源**，`sum(counts)` 硬校验通过才输出。

### 22.2 「最近交易日价格」专项口径（用户点名）

- 取**收盘价 close，不取「最新价/last」**：盘前无盘中价；收盘价确定、可回测；避免盘中价使涨跌幅与结论漂移。
- 复权口径（**P0-2 已拍板：不复权**）：`price_close` 与 `pct_change` 均取**不复权当日序列**，登记进 `config/calc_version`；除权除息日须在卡片标注「本日含除权因素，价格与涨跌幅不可与前一日直接比较」，避免把跳空误读成趋势。多日指标计算若需复权序列，须单独取数并显式标注口径，**不得与展示价格混用**。
- **三时间分离**：`data_date`（行情基准日）、`decision_time`（建议生成时点，盘前）、`render_time`（打开时刻，仅展示）；**禁用「今日/实时/最新」**。
- 逐情形降级：非交易日 → 展示上一次成功快照 + 表头「非交易日不更新」；停牌 → 显示**停牌前最后收盘价**并强制标注「停牌前收盘价（{price_date}）」、涨跌幅「—」、`advice=不可操作`、`price_date≠data_date` 显式提示；数据缺失 → 「—/暂无」、`advice=null`，**严禁旧值冒充 / 0 填充 / 编造**；三元组不一致 → 「操作建议：待同步」，不显旧值。
- 红涨绿跌仅视觉编码，不改数值口径。

### 22.3 `advice` 档位体系与守卫（「暂无信号 ≠ 观望」）

**存储层两字段**：`advice`（枚举 or `null`：持仓 `{加仓,持有,减仓,清仓}`、未持仓 `{等待买点,观望,等待卖点}`、停牌 `{不可操作}`、数据不足→`null`）与 `advice_state`（`{有效,待同步,无数据,不生成,不可操作}`）。展示层唯一输出 `advice_display` 共 **11 档** = 硬约束态 4 档 + 有效意见 7 档。

> **硬约束**：「观望」是评分模型产出的**有效**操作意见；「不生成意见/待同步/无数据/不可操作」是**状态位**，灰色 + 明确文字（如「数据不足，未生成意见」），**禁止留白或渲染成「观望」**。「暂无紧急信号」仅表示 `signal_flag` 为空，不得转写为任何操作意见。

**判定优先序（守卫短路，从高到低）**：

| 序 | 守卫 | 输出 | 进评分 |
| --- | --- | --- | --- |
| S0 | 三元组不一致（**渲染层前置守卫**） | 待同步，不显旧值 | 否 |
| S1 | `suspended=true` | 不可操作 | 否 |
| S2 | `data_sufficient=false` / 关键输入缺 | `advice=null` 或「无数据」 | 否 |
| S3 | 大盘/板块 degraded | 注记 + 置信度下调，**档位不变** | 是（中性/不明代入） |
| S4 | 触及趋势失效位/止损参考 | 收敛至 减仓/清仓（持仓）或 等待卖点（未持仓），标注「风险控制优先于评分」 | 覆盖评分 |
| S5 | 建议层决策表（`is_holding` 分支） | 7 档有效意见之一 | 是 |
| S6 | 仓位/集中度约束 | 只裁剪仓位建议，档位不变 | — |

展示排序权重 `signal_priority` 与判定序**用途不同**：判定序决定「是什么档」，展示序决定「排第几」，**均不改 advice 真值**。

### 22.4 排序 / 空态 / 交互

- 默认排序：`signal_priority` 升序（紧急置顶）→ 操作意见分组（枚举固定序）→ `code` 升序稳定兜底；**禁止默认按涨跌幅动态排序导致刷新跳变**。可切换排序**只改展示顺序不改结论值**，均带稳定次级键。
- 空态：无自选→引导添加；无快照→「暂无数据，最近交易日盘前生成后可见」；全部停牌→仍列出、建议列统一「不可操作」；部分数据不足→单只降级不影响其他行；非交易日→展示历史快照 + 表头标注。
- **整行单一点击热区**（覆盖 5 个字段）→ 详情页；键盘可聚焦、回车触发。紧急信号角标首版纯标记、不设独立点击。

## 附录 A：原始需求原话

> 以下为用户 2026-11-10 提供的原文，逐条保留，未作改写。

**1. 目标与定位**
个人使用，分析 A 股股票和 ETF，约 10 只自选。
中长线为主，每天开盘前辅助决策，不做盘中实时分析。
输出顺序：先操作意见，后分析原因。
技术面为主，基本面/估值辅助；股票与 ETF 规则分开。
每只标的一张结论卡片。

**2. 趋势与位置判断**
底仓趋势默认 B 方案：周线为主 + 日线辅助 + 月线背景过滤。
做 T 用日线辅助，不改变底仓趋势结论。
趋势结论三档：偏强 / 中性 / 偏弱。
高位/低位：至少 2 类指标同向才下标签；冲突降级为中性/不明。
位置指标：价格分位、前高前低回撤/涨幅、均线偏离、箱体位置；布林带辅助。
高位/低位不单独触发买卖，只影响操作意见加减分和风险提示。

**3. 操作意见**
已持仓：加仓 / 持有 / 减仓 / 清仓。
未持仓：等待买点 / 观望 / 等待卖点。
等待卖点也用于未持仓回避。
做 T 计划并入卡片。

**4. 关键价位**
必须有：
支撑位 1–2 个、压力位 1–2 个；
趋势失效位/止损参考位；
每个价位来源说明：前高前低、箱体边界、重要均线、缺口等。
建议有：
关注买点区（未持仓）；
减仓/止盈区（已持仓）；
仓位建议，服从不超仓规则。
可选：突破确认位、回踩确认位。

**5. 仓位管理**
单只上限：单只市值 / 总资金 ≤ 20%。
总仓位 ≤ 80%；现金 ≥ 20%。
不按股票/ETF 种类设行业硬上限；行业集中度只提示不硬限。
统一硬上限 + 动态基础建议 + 行业集中度提示。
卡片显示：百分比区间 + 轻/中/重档位。

**6. 做 T 规则**
短波 T：几天到两周不限，允许单 T。
底仓不动，只用 T 仓做 T。
T 仓 ≤ 当前该股最高可用资金的 10%。
当前股最高可用资金 = min（该股单只上限 20% × 总资金 − 该股现有底仓市值，现金可用部分）。
T 仓计入单只 20% 和总仓位 80% 限制，不得超仓。
允许反 T，但必须有底仓；反 T 只允许卖出 T 仓，底仓不动。
禁止杠杆/融资。
单次 T 亏损上限：总资金 0.75%。
工具只给盘前 T 计划：参考区间、失效位、T 仓上限、止损参考，不给盘中实时信号。

**7. 数据源**
免费、无需 token、无积分，稳定优先；不稳定接口排除。
策略：akshare 为主，公开接口备用，本地缓存兜底，质量校验降级。
连续 3 个交易日失败，或关键字段缺失率 >5%，该源降级/排除。
基本面按季度更新并缓存，失败不阻塞报告。
报告注明数据日期和数据源；缓存数据明确标注。
自选股和持仓手动配置。

**8. 盘前口径**
用前一交易日收盘数据 + 最新已披露财报。
不纳入集合竞价、隔夜消息、盘前涨跌、当天新闻。
盘前输出"条件计划"，不是预测。
开盘后不更新结论。
报告标注"数据截止 X 日收盘"。
非交易日不生成正式报告；飞书提示非交易日。
停牌标"不可操作"；ST 加风险提示；数据不足标"数据不足，不生成操作意见"。

**9. 运行与输出**
Windows 或 Linux，每天开机运行。
每天 7:30 自动生成，8:00 前可查看。
输出：本地 HTML 汇总页 + 每只标的卡片；另可导出 Markdown/Excel。
飞书推送：摘要 + 完整卡片文本或链接推送，非文件；webhook 后续提供，先做可配置项；未配置时只生成本地 HTML。
报告历史保留最近 60 个交易日，用于复盘；支持按标的筛选历史卡片。

**10. 卡片结构**
操作意见 → 趋势结论 → 当前位置 → 关键价位 → 理由 → 风险提示 → 仓位建议（百分比区间 + 轻/中/重）→ 做 T 计划。

**11. 验证与验收**
第一版做简单纸面回看，不自动交易。
验收标准：8 点前生成、约 10 只标的、卡片字段完整、不超仓、数据日期清晰、飞书可推送、异常有标注。

**12. 明确不做**
不做盘中实时分析；
不自动交易；
不融资杠杆；
不做消息面情绪判断；
不承诺收益，不构成投资建议。

**13. 新增需求（第 5 轮，2026-11-10）**
以上是单个标的的分析，新增一个页面是大盘和板块的分析；
大盘分析在上面，下面是板块或者概念的分析；
板块不要所有的板块分析，仅分析标的涉及的，每个板块分析内容最下方有个提醒，相关标的有 xxx；
大盘板块在一个 tab，切换 tab 到个股列表页，列表页展示每个标的的名称、编码、最近交易日的价格、涨跌幅、操作建议；
点击标的进入单个标的的详情页；
帮我细化大盘、板块、个股的展示和分析信息。
