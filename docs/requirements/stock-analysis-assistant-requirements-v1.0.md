| 编号 | 需求 | 状态 |
| --- | --- | --- |
| FR-2.1 | 底仓趋势默认 **B 方案**：周线为主 + 日线辅助 + 月线背景过滤 | 已明确（「B 方案」为用户内部代号，其他方案未定义，不臆造） |
| FR-2.2 | 做 T 使用日线辅助，**不改变底仓趋势结论** | 已明确 |
| FR-2.3 | 趋势结论固定三档：`偏强` / `中性` / `偏弱` | 已明确；分档阈值〔待确认〕 |
| FR-2.4 | 高位/低位标签：**至少 2 类指标同向**才下标签；指标冲突时降级为 `中性` / `不明` | 已明确 |
| FR-2.5 | 位置主指标 4 类：价格分位、前高前低回撤/涨幅、均线偏离、箱体位置；布林带仅作辅助 | 已明确 |

**〔解释〕** FR-2.4 的「2 类」按 FR-2.5 的 4 类主指标计，布林带不单独算一类；此解释需确认，见 §7-Q3。

**验收要点**：同一标的反复生成，趋势结论必为三档之一；出现指标冲突时位置标签不得为高位/低位；做 T 计划存在时底仓趋势结论与无 T 计划时一致。

## 4. FR-4 关键价位

按「必须有 / 建议有 / 可选」三级管理，避免字段虚报。

| 级别 | 字段 | 要求 |
| --- | --- | --- |
| **必须有** | 支撑位 | 1–2 个 |
| **必须有** | 压力位 | 1–2 个 |
| **必须有** | 趋势失效位 / 止损参考位 | 1 个 |
| **必须有** | 每个价位的**来源说明** | 前高前低 / 箱体边界 / 重要均线 / 缺口等 |
| 建议有 | 关注买点区 | 未持仓时 |
| 建议有 | 减仓 / 止盈区 | 已持仓时 |
| 建议有 | 仓位建议 | 服从不超仓规则（见 FR-5） |
| 可选 | 突破确认位、回踩确认位 | — |

**验收要点**：任一价位缺来源说明即判卡片不完整；「必须有」字段不得为空，无值时应显式标注「数据不足」而非填空或编造。

## 5. FR-5 仓位管理

### 5.1 硬上限（统一口径，不可突破）

| 约束 | 公式 |
| --- | --- |
| 单只上限 | `单只市值 / 总资金 ≤ 20%` |
| 总仓位上限 | `总持仓市值 / 总资金 ≤ 80%` |
| 现金下限 | `现金 ≥ 总资金 × 20%` |
| T 仓计入 | T 仓**同时**计入单只 20% 与总仓位 80% 限制 |

### 5.2 建议层

- 采用「**统一硬上限 + 动态基础建议 + 行业集中度提示**」三层结构。
- **不按股票/ETF 种类设行业硬上限**；行业集中度**只提示、不硬限**。
- 卡片显示：**百分比区间 + `轻` / `中` / `重` 档位**。
- 优先级：硬上限 > 动态基础建议；位置标签、趋势评分只影响建议层，不得突破硬上限。

**〔待确认〕** 总资金的定义与更新频率、动态基础建议的评分口径、行业集中度提示阈值、轻/中/重与百分比区间的映射（见 §7-Q1/Q4/Q5）。

**验收要点**：对每张卡片反算仓位，单只与总仓位均不得越界；建议区间上限不得超过该标的剩余可用额度。

## 6. FR-6 做 T 规则

| 编号 | 需求 | 状态 |
| --- | --- | --- |
| FR-6.1 | 短波 T：几天到两周不限；允许单 T | 已明确；「单 T」释义〔待确认，Q6〕 |
| FR-6.2 | **底仓不动**，只用 T 仓做 T | 已明确 |
| FR-6.3 | T 仓 ≤ 当前该股最高可用资金的 **10%** | 已明确 |
| FR-6.4 | `当前股最高可用资金 = min(20% × 总资金 − 该股现有底仓市值, 现金可用部分)` | 已明确 |
| FR-6.5 | T 仓计入单只 20% 与总仓位 80% 限制，**不得超仓** | 已明确 |
| FR-6.6 | 允许反 T，但**必须有底仓**；反 T 只允许卖出 T 仓，底仓不动 | 已明确；反 T 时序口径〔待确认，Q7〕 |
| FR-6.7 | **禁止杠杆/融资** | 已明确 |
| FR-6.8 | 单次 T 亏损上限：`总资金 × 0.75%` | 已明确 |
| FR-6.9 | 工具**只给盘前 T 计划**：参考区间、失效位、T 仓上限、止损参考；**不给盘中实时信号** | 已明确 |

**〔解释〕** 当 `20% × 总资金 − 底仓市值 ≤ 0` 或现金不足时，T 仓上限为 0，卡片不出 T 计划并标注原因。此为满足 FR-6.5 的必然推论，需与 Q1 的总资金口径一并确认。

**验收要点**：T 仓金额、单次 T 最大亏损须同时满足 FR-6.3/FR-6.8 与 FR-5 硬上限；任一越界即判失败。

## 7. FR-7 数据源与质量

### 7.1 准入与取数策略

- 准入：**免费、无需 token、无积分、稳定优先；不稳定接口排除**。
- 主源 **akshare** → 公开接口备用 → 本地缓存兜底；**质量校验后降级**。

### 7.2 降级 / 排除触发

| 触发条件 | 动作 |
| --- | --- |
| 该源**连续 3 个交易日**取数失败 | 降级或排除 |
| **关键字段缺失率 > 5%** | 降级或排除 |

### 7.3 其余口径

- 基本面数据**按季度更新并缓存**，取数失败**不阻塞报告**。
- 报告注明**数据日期**与**数据源**；使用缓存数据时**明确标注**。
- 自选股与持仓**手动配置**。

**〔待确认〕** 「关键字段」清单、缺失率统计窗口、公开接口白名单、缓存有效期、交易日历来源（Q8）。

**验收要点**：报告可追溯到每个字段的日期与来源；缓存数据有可见标识；基本面失败时仍能出报告。

## 10. FR-10 卡片结构

顺序固定，不得调换：

```
操作意见 → 趋势结论 → 当前位置 → 关键价位 → 理由 → 风险提示
        → 仓位建议（百分比区间 + 轻/中/重）→ 做 T 计划
```

### 10.1 字段契约〔解释性补全，供方案阶段细化〕

| 区块 | 关键字段 | 必填 | 空值处理 |
| --- | --- | --- | --- |
| 操作意见 | 意见枚举、持仓状态、数据截止日 | 是 | 异常态按 FR-3.5 / FR-8.7 标注 |
| 趋势结论 | `偏强`/`中性`/`偏弱`、B 方案说明 | 是 | 数据不足则标注，不猜档 |
| 当前位置 | 高位/低位/中性/不明、同向指标数 | 是 | 冲突时降级为中性/不明 |
| 关键价位 | 支撑 1–2、压力 1–2、失效位/止损位、各价位来源 | 是 | 显式「数据不足」 |
| 理由 | 技术面主因、基本面/估值辅助 | 是 | 辅助缺失需标注 |
| 风险提示 | ST、停牌、行业集中度、位置风险、缓存数据 | 是 | 无风险也需明示「无特别提示」 |
| 仓位建议 | 百分比区间、轻/中/重、硬上限校验结果 | 是 | 不得超过剩余额度 |
| 做 T 计划 | 参考区间、失效位、T 仓上限、止损参考 | 条件必填 | 不具备条件时标注原因 |

每张卡片另需携带元信息：**数据截止日、数据源、是否缓存、生成时间、标的类型（股票/ETF）、免责声明**。

## 13. 补充：规则优先级与异常降级矩阵〔解释性补全〕

### 13.1 规则优先级

1. 硬上限（FR-5、FR-6.5）**最高**，任何评分、建议、位置标签都不得突破。
2. 异常态（停牌 / 数据不足 / 非交易日）**高于**常规意见生成。
3. 底仓趋势结论由周线主导（FR-2.1），做 T 不改变它（FR-2.2）。
4. 位置标签只影响操作意见加减分与风险提示（FR-2.6）。
5. 报告一经生成，开盘后不更新（FR-8.4）。

### 13.2 异常降级矩阵

| 情形 | 卡片行为 | 汇总页 / 推送行为 |
| --- | --- | --- |
| 非交易日 | 不生成正式卡片 | 飞书提示「非交易日」；本地不产正式报告 |
| 停牌 | 标 `不可操作` | 汇总页列明 |
| ST | 正常出意见 + 风险提示 | 汇总页列明 |
| 数据不足 | 标 `数据不足，不生成操作意见` | 汇总页列明，不静默跳过 |
| 主数据源失败 | 依次走备用 → 缓存；缓存需标注 | 注明实际数据源 |
| 连续 3 日失败 / 缺失率 > 5% | 该源降级或排除 | 注明降级状态 |
| 基本面取数失败 | 辅助信息缺失，报告照常生成 | 标注缺失 |
| 飞书未配置 | 无影响 | 只生成本地 HTML |
| 剩余可用额度为负 | 仓位建议为 0，无 T 计划 | 标注原因 |

## 14. 事实、假设与待确认问题

### 14.1 事实与假设

| 项目 | 类型 | 来源 | 影响 | 验证方式 |
| --- | --- | --- | --- | --- |
| 用户个人使用、约 10 只自选、中长线、盘前决策 | 事实 | 用户原话 §1 | 决定规模与输出形态 | 无需验证 |
| 飞书 webhook 尚未提供 | 事实 | 用户原话 §9 | 第一版需可配置且能降级 | 配置联调（A6） |
| 第一版只做纸面回看 | 事实 | 用户原话 §11 | 不接交易接口 | 验收确认 |

## 附录 A：原始需求原话

> 以下为用户 2026-11-10 提供的原文，逐条保留，未作改写。

**1. 目标与定位**
个人使用，分析 A 股股票和 ETF，约 10 只自选。
中长线为主，每天开盘前辅助决策，不做盘中实时分析。
输出顺序：先操作意见，后分析原因。
技术面为主，基本面/估值辅助；股票与 ETF 规则分开。
每只标的一张结论卡片。

**2. 趋势与位置判断**
底仓趋势默认 B 方案：周线为主 + 日线辅助 + 月线背景过滤。
做 T 用日线辅助，不改变底仓趋势结论。
趋势结论三档：偏强 / 中性 / 偏弱。
高位/低位：至少 2 类指标同向才下标签；冲突降级为中性/不明。
位置指标：价格分位、前高前低回撤/涨幅、均线偏离、箱体位置；布林带辅助。
高位/低位不单独触发买卖，只影响操作意见加减分和风险提示。

**3. 操作意见**
已持仓：加仓 / 持有 / 减仓 / 清仓。
未持仓：等待买点 / 观望 / 等待卖点。
等待卖点也用于未持仓回避。
做 T 计划并入卡片。

**4. 关键价位**
必须有：
支撑位 1–2 个、压力位 1–2 个；
趋势失效位/止损参考位；
每个价位来源说明：前高前低、箱体边界、重要均线、缺口等。
建议有：
关注买点区（未持仓）；
减仓/止盈区（已持仓）；
仓位建议，服从不超仓规则。
可选：突破确认位、回踩确认位。

**5. 仓位管理**
单只上限：单只市值 / 总资金 ≤ 20%。
总仓位 ≤ 80%；现金 ≥ 20%。
不按股票/ETF 种类设行业硬上限；行业集中度只提示不硬限。
统一硬上限 + 动态基础建议 + 行业集中度提示。
卡片显示：百分比区间 + 轻/中/重档位。

**6. 做 T 规则**
短波 T：几天到两周不限，允许单 T。
底仓不动，只用 T 仓做 T。
T 仓 ≤ 当前该股最高可用资金的 10%。
当前股最高可用资金 = min（该股单只上限 20% × 总资金 − 该股现有底仓市值，现金可用部分）。
T 仓计入单只 20% 和总仓位 80% 限制，不得超仓。
允许反 T，但必须有底仓；反 T 只允许卖出 T 仓，底仓不动。
禁止杠杆/融资。
单次 T 亏损上限：总资金 0.75%。
工具只给盘前 T 计划：参考区间、失效位、T 仓上限、止损参考，不给盘中实时信号。

**7. 数据源**
免费、无需 token、无积分，稳定优先；不稳定接口排除。
策略：akshare 为主，公开接口备用，本地缓存兜底，质量校验降级。
连续 3 个交易日失败，或关键字段缺失率 >5%，该源降级/排除。
基本面按季度更新并缓存，失败不阻塞报告。
报告注明数据日期和数据源；缓存数据明确标注。
自选股和持仓手动配置。

**8. 盘前口径**
用前一交易日收盘数据 + 最新已披露财报。
不纳入集合竞价、隔夜消息、盘前涨跌、当天新闻。
盘前输出"条件计划"，不是预测。
开盘后不更新结论。
报告标注"数据截止 X 日收盘"。
非交易日不生成正式报告；飞书提示非交易日。
停牌标"不可操作"；ST 加风险提示；数据不足标"数据不足，不生成操作意见"。

**9. 运行与输出**
Windows 或 Linux，每天开机运行。
每天 7:30 自动生成，8:00 前可查看。
输出：本地 HTML 汇总页 + 每只标的卡片；另可导出 Markdown/Excel。
飞书推送：摘要 + 完整卡片文本或链接推送，非文件；webhook 后续提供，先做可配置项；未配置时只生成本地 HTML。
报告历史保留最近 60 个交易日，用于复盘；支持按标的筛选历史卡片。

**10. 卡片结构**
操作意见 → 趋势结论 → 当前位置 → 关键价位 → 理由 → 风险提示 → 仓位建议（百分比区间 + 轻/中/重）→ 做 T 计划。

**11. 验证与验收**
第一版做简单纸面回看，不自动交易。
验收标准：8 点前生成、约 10 只标的、卡片字段完整、不超仓、数据日期清晰、飞书可推送、异常有标注。

**12. 明确不做**
不做盘中实时分析；
不自动交易；
不融资杠杆；
不做消息面情绪判断；
不承诺收益，不构成投资建议。
