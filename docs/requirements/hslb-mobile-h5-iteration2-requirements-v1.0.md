## 1. 本次要解决什么

M1 上线后首页只有自选股列表，**缺少"今天大盘是什么环境"的前置判断**；详情页「板块」是占位。导致：

1. 看到"减仓"时，分不清是大盘拖累还是个股走弱；
2. 不知道这只票属于哪个行业、行业今天强不强，无法归因。

本次新增：**首页「大盘」卡片**（上证核心指标 + 环境评级 + 一句建议 + 一段总结）、**详情页「板块」块**（行业归属 + 当日表现 + 排名 + 相对强弱 + 一句结论）。

## 3. FR-H · 首页大盘块

### 3.1 指标

**主数值**：收盘点位 + 当日涨跌幅（大字号，涨红跌绿）。

**指标格 6 个（2×3）**：

| # | 指标 | 计算口径 | 展示示例 |
| --- | --- | --- | --- |
| H2 | MA20 位置 | `close` 相对 `MA20` 的偏离 | 「上方 +1.2%」/「下方 -0.8%」 |
| H3 | 均线排列 | MA5 / MA10 / MA20 相互关系 | 「多头排列」/「空头排列」/「均线纠缠」 |
| H4 | 量能比 | 当日成交量 ÷ 5 日均量 | 「0.86×（缩量）」/「1.35×（放量）」 |
| H5 | RSI(14) | 现有指标快照 | 「58（中性）」/「72（偏热）」 |
| H6 | 20 日位置 | `(close-low20)/(high20-low20)` | 「72%（偏上）」/「28%（偏下）」 |
| H7 | 5 日涨幅 | `close / close[-5] - 1` | 「+2.1%」/「-3.4%」 |

> 原方案的 ATR% 已替换为 5 日涨幅（ATR% 对新手无参照系，"1.1%" 无法判断大小）。
> 备选（本轮不做）：ATR%、MACD 状态、全市场涨跌家数（需全市场快照，慢且盘后易缺）。

### 3.2 环境评级（2×2 矩阵，覆盖全部组合）

> 修订原因：v0.1 只覆盖"站上 MA20 + MA20 上行"和"跌破 MA20 + MA20 下行"两个象限，
> 另两种组合会被错判成"震荡 / 区间对待"，文案与实际趋势相反。

| 价格 vs MA20 | MA20 斜率 | 环境 | 建议文案 |
| --- | --- | --- | --- |
| 上方 | 上行 | **偏多** | 量能 ≥1.0：趋势与量能同向，回踩 MA20 不破可分批低吸；量能 <1.0：缩量上行，追高性价比低，等回踩再加 |
| 下方 | 上行 | **趋势回调** | 上升趋势中的回调，等站回 MA20 且缩量止跌再加，不追杀 |
| 上方 | 下行 | **下跌反弹** | 反弹不追、不重仓；站不稳 MA20 视为未反转 |
| 下方 | 下行 | **偏空** | 控制仓位，反弹不宜加仓；等站回 MA20 再谈 |

**修饰条件**（不改变主评级，最多展示 2 条）：

| 条件 | 附加提示 |
| --- | --- |
| `MA5 < MA10` | 「短期均线转弱」 |
| 量能比缺失 | 「量能数据缺失，仅按价格与均线判断」（评级降级为两因子） |
| RSI > 70 或 20 日位置 > 85% | 「短期偏热，注意冲高回落」 |
| RSI < 30 | 「超卖，留意反弹」 |
| `close == MA20` | 归入"上方"分支，并标注「贴近 MA20，方向待确认」 |

**边界**：`high20 == low20`（停牌 / 一字板）时位置返回 `null`，显示 `-`，不参与修饰判断。

### 3.3 一段总结（2~3 句，模板拼装）

```
上证收于 {close}（{涨跌}），{趋势句}，{量能句}。
环境{评级}，操作上{建议句}（个股仍按各自纪律执行）。
自选股 {N} 只中，{x} 只需减/清、{y} 只可加/建、{z} 只观望{，另有 k 只暂无信号}。
```

**硬约束**：`x + y + z + k == N`，不成立时**省略第三句**，绝不输出对不上的数字。

**禁用表述**：不出现"建议总仓位 X 成"（账户总资金未纳入）；不出现"建议换股"（相对强弱未剔除市值因子）。

### 3.4 失败与降级

| 场景 | 表现 |
| --- | --- |
| 指数行情取不到 | 卡片保留标题 + 「大盘数据暂不可用」，列表照常 |
| 历史不足 `min_bars`（**60 根**） | **整块降级**为「数据不足，暂不评级」，不展示半套指标 |
| 成交量缺失（部分指数源不返回 volume） | 量能比显示 `-`，标注「量能数据缺失」，评级只用价格/均线 |
| 非交易日 / 盘前 | 用最近交易日数据，标题标注「截至 {日期}」 |

> `min_bars=60`：MA20 斜率需 21 根，MA60 与 ATR 需更长；`build_indicator_snapshot` 默认 21 根会导致指标失真。

## 4. FR-D · 详情页板块块

**位置调整（已确认）**：由第 5 位提到第 3 位——
`技术面 → 板块 → 风险 → 大盘 → 消息面`。理由：板块回答"是个股问题还是行业问题"，是归因信息，决策价值高于消息面。

### 4.1 展示字段

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| 所属行业 | 银行 | 个股 → 行业归属 |
| 板块当日涨跌 | +0.83% | 同源行业板块指数 |
| 行业排名 | 12 / 86 | 在全行业当日涨幅中的名次 |
| 个股 vs 板块 | -0.20% | 个股涨跌 − 板块涨跌 |
| 板块内宽度 | 上涨 32 / 下跌 12 | 数据源已带，**纳入 M2-B**（不是可选项） |
| 一句话结论 | 银行板块 +0.83%（12/86），个股 -0.20% 略弱于板块，属行业普涨下的跟涨。 | 模板拼装 |

### 4.2 结论规则

- 板块涨跌 > 0 且排名前 20% → 「板块强势」；涨跌 > 0 但排名中后 → 「板块温和跟涨」；
- 板块涨跌 < 0 且排名后 20% → 「板块走弱」；
- 相对强弱 > +1% → 「个股强于板块（有独立逻辑）」；< -1% → 「个股弱于板块（跑输行业）」；
- 相对强弱在 ±1% 内 → 「与板块基本同步」；
- 文案末尾统一加：「相对强弱未剔除市值因子，仅作参考，不构成换股建议」。

### 4.3 数据来源与实现约束（**评审后修正**）

| 数据 | 来源 | 约束 |
| --- | --- | --- |
| 个股所属行业 | 东财 `stock_individual_info_em`（行业字段） | 与板块排行**同源**（东财口径）；缓存 7 天 |
| 行业板块全量快照 | **新增** `get_sector_quotes()`（或直接调 `stock_board_industry_name_em`） | **现有 `get_sector_rankings()` 只返回 top/bottom n，拿不到"12/86"**；必须保留全量 DataFrame |
| 板块内涨跌家数 | 同上（数据源已含上涨/下跌家数） | 0 额外调用 |
| Baostock 行业分类 | **本轮不接入** | 申万/证监会分类与东财板块名不是一套，无法参与匹配；且登录开销大。行业取不到时板块块整体降级，不硬凑 |

**名称归一化**：去掉「板块」后缀、统一全角/半角括号、去空格后再匹配；匹配失败时 `ranking = null`，显示「板块排名暂不可用」，不猜、不硬凑。

**时效一致性**：板块数据与个股行情必须取**同一个交易日**（`trade_date`），页面上只标注一个"数据截至"，避免板块停在昨天、个股是今天。

**缓存解耦**：`market` 缓存 15 分钟、`items` 缓存 15 秒（下拉刷新不应重算指数）；支持 `?with_market=false` 只取列表。

### 5.2 `GET /api/v1/h5/stocks/{code}` 板块块

`analysis[]` 的 `sector` 由占位改为真实数据，并追加结构化字段：

```json
{
  "key": "sector",
  "label": "板块",
  "verdict": "银行板块 +0.83%（12/86），个股 -0.20% 跑输板块…",
  "tone": "neutral",
  "available": true,
  "details": [{"label": "所属行业", "value": "银行"}],
  "sector_detail": {
    "industry": "银行",
    "change_pct": 0.83,
    "rank": 12,
    "total": 86,
    "relative_pct": -0.20,
    "advancers": 32,
    "decliners": 12,
    "ranking_available": true
  }
}
```

**单一事实源**：`verdict` 必须由 `sector_detail` 生成；前端渲染结构化字段，**不得二次拼接文案**，避免两处数字不一致。

### 5.3 缓存与配置

- 所有板块 / 行业缓存 key **必须带 `trade_date`**，跨日自动失效（否则 23:59 缓存的排行次日仍在用）；
- 假设**单进程**部署（内网 `uvicorn` 单 worker）；多 worker 时缓存各自独立，行为一致但不共享；
- 新增配置：`HSLB_H5_SECTOR_CACHE_SECONDS`（默认 900）、`HSLB_H5_INDUSTRY_CACHE_SECONDS`（默认 604800）、`HSLB_H5_MARKET_CACHE_SECONDS`（默认 900）。

## 9. 验收标准

1. 打开 `/h5`：首屏先见大盘卡片（点位 + 6 指标 + 评级 + 建议 + 总结），下滑见列表，首屏仍露出 ≥2 行；
2. 总结中每个数字都能在卡片或列表中找到对应项；四类计数之和 = N；
3. 评级矩阵 4 个分支均有单测覆盖，含边界：`close==MA20`、量能比 `==1.0`、量能缺失；
4. 固定 120 根指数日线的**黄金样本**：断言 6 个指标值与评级结果，防止调参悄悄改口径；
5. 详情页板块块显示行业、涨跌、排名、相对强弱、家数、结论；排名缺失时显示「板块排名暂不可用」；
6. 行业取不到 → 仅板块块降级，其余四块不受影响；
7. 指数取不到 → 大盘卡片降级提示，列表照常可用；
8. 跨日场景：把 `trade_date` 改成前一交易日，缓存必须失效重取（单测模拟）。

### 11.2 与文档的差异（如实记录）

1. **Baostock 回退未接入**：需求 §4.3 曾写"仅展示行业名"，实施时判断其登录开销大、分类体系不同，且展示价值有限，直接去掉；行业取不到时板块块显示「行业归属暂不可用」。
2. **量能阈值**：格式统一为 `≥1.1 放量 / ≤0.9 缩量 / 其余平量`；评级分支仍以 `≥1.0` 区分放量/缩量（两者用途不同，已在代码注释说明）。
3. **新增 `?with_market=false`**：文档 §5.1 提到，实施为查询参数；缓存仍保留完整 payload，仅响应裁剪。
